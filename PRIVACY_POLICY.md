## Information We Collect

### 1. Task Data
We collect and store the following information you provide:
- Task titles and descriptions
- Priority levels (A, B, C, D, E)
- Urgency and importance ratings
- Due dates and completion status
- Task categories and notes
- Scheduled time blocks

### 2. Analytics Data
We collect limited analytics to improve the app:
- App launch events
- Session duration
- Feature usage (breathing exercises, weekly schedule views)
- App version and device type

**Important:** We do NOT collect:
- Your name or email address
- Location data
- Device identifiers for tracking
- Contacts or photos
- Any personally identifiable information

## How We Use Your Information

### Task Data
- **Storage:** All task data is securely stored in Supabase (cloud database)
- **Purpose:** To provide core app functionality (task management, prioritization)
- **Access:** Only you can access your task data through the app
- **Backup:** Your data is automatically backed up to enable sync across devices

### Analytics Data
- **Purpose:** To understand app usage and improve features
- **Processing:** Aggregated analytics to measure app performance
- **Not Used For:** Advertising, tracking, or selling to third parties

## Data Storage and Security

### Cloud Storage (Supabase)
- All task data is encrypted in transit (HTTPS/TLS)
- Data is stored on secure Supabase servers
- We implement industry-standard security practices
- No data is shared with third parties

### Local Storage
- Some preferences are stored locally on your device
- Local data is protected by iOS security features

## Data Sharing
